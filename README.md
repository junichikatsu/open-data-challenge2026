## 1. プロジェクト概要・解く社会課題

2026年の台風・線状降水帯による豪雨では、**「都市鉄道の運転見合わせ」と「道路アンダーパス・地下道冠水」が同一の1〜2時間に多発**しました。車や歩行者が冠水したガード下に進入して立ち往生・水没する痛ましい事故が発生しています。

- **情報の分断**: 鉄道の運行情報（運休・遅延）と道路の冠水リスクは別々の機関から公開され、利用者が同一地図で把握する術がありませんでした。
- **駅出口の落とし穴**: 駅の出口選択（GTFS-Pathways）を誤ると、出た直後にすり鉢状の冠水アンダーパスに直面してしまいます。
- **行政データの非構造化**: 国交省が公表するアンダーパス冠水注意箇所リスト（都内159箇所・全国約3,800箇所）は PDF 形式にとどまり、緯度経度やバス路線（GTFS shapes）との空間結合がなされていませんでした。さらに2026年10月6日改定の国交省新ガイドライン「4区分判定」への対応が急務となっています。

**「アメミチ 3D」**は、これらのオープンデータを3D都市空間上で統合し、**平常時（事前学習・市民点検）から豪雨時（避難・迂回ナビ）、行政（設備判定）までをシームレスにつなぐフェーズフリーなWeb3Dアプリケーション**です。

## 3. 審査員向け「3分でわかる」操作ツアー

オンラインデモを開き、以下の順序で操作いただくと本システムのコアバリューをご体感いただけます。

```
[デモURLアクセス] 
   │
   ├─► ① 豪雨時モード「17:15 シナリオ再生」（右上ボタン）
   │      └─ 降雨開始 → 地下鉄運休 → 冠水アンダーパス閉鎖 → アメミチ推奨線・都06バス誘導
   │
   ├─► ② 雨量スライダー操作（左下）
   │      └─ 0〜100mm/h で変化する3Dすり鉢状窪地の動的水位表現
   │
   ├─► ③ 平時モード「アメミチづくり」
   │      └─ 地図上をクリックして避難ルートを描画 → 幾何安全度を即座に100点採点
   │
   ├─► ④ 平時モード「見てきた」現地報告
   │      └─ アンダーパスピンをクリック → 赤色灯・道路情報板・水位計の3値点検
   │
   └─► ⑤ 管理者タブ「4区分判定ダッシュボード」
          └─ 都内159箇所の検索・フィルター・国交省最新4区分自動判定・CSV出力
```

### ① 豪雨時モード「17:15 シナリオ再生エンジン」
画面上部の**「🚨 豪雨時: 避難ナビ」**タブに切り替え、右上の**「▶ 17:15 シナリオ再生」**をクリックします。
- **16:50**: 降雨開始（20mm/h）。
- **17:10**: ゲリラ豪雨に急変（65mm/h）、浜松町・大門駅周辺のアンダーパスが警戒水域に到達。
- **17:15**: 都営地下鉄（浅草線・大江戸線）全線運転見合わせが発令。駅出入口（B1/B2等）が冠水リスクにより閉鎖表示。
- **17:20**: 安全な「B3 出口（デッキ直結）」および冠水を避ける**安全推奨ライン（アメミチライン）**が自動描画。同時に冠水を回避して運行を継続する**都営バス「都06系統」**への乗換誘導と、高台一時滞在施設への避難指示が発動します。
- *(倍速ボタン（1x / 2x / 5x）で再生スピードを変更可能)*

### ② 平時モード「アメミチづくり（安全避難ルート描画＆採点）」
**「☀️ 平時: アメミチ探索」**タブのツールパネルで**「✏️ アメミチを描く」**をクリック。
- 地図上を順にクリックして自宅や目的地までのルートを描線。
- **「✅ ルート完成・安全診断」**を押すと、アンダーパス危険バッファ（250m/120m/50m）・標高勾配・都営バス安全幹線との近接性をアルゴリズムが幾何計算し、**100点満点で即座に採点＆S/A/B/Cランク診断モーダル**を表示します。

### ③ 平時モード「見てきた（現地設備チェック・3値報告）」
- 地図上のアンダーパスピンをクリックすると、**「現地設備 3値アンケート」**モーダルが開きます。
- 「赤色回転灯」「道路情報板」「水位センサ・標示」の有無を「はい／いいえ／わからない」で報告。
- 市民による複数報告の一致によりデータが確定し、管理者ダッシュボードへリアルタイム同期されます。
- *(フェイルセーフ: 雨量スライダーが50mm/h以上の豪雨状態では、安全のため現地調査ボタンが自動ロックされます)*

### ④ 管理者モード「国交省4区分判定ダッシュボード」
**「🏛️ 管理者: 4区分判定」**タブをクリック。
- 東京都全域159箇所のアンダーパス注意箇所を一覧表示。
- エリア（港区・品川区・大田区・新宿区・渋谷区等）や鉄道交差有無、バス運行路線数で瞬時に絞り込み。
- 国交省ガイドライン（2026-10-06改定）に基づく「4区分（特定アンダーパス〜一般）」の判定根拠を確認し、**「📥 判定結果CSV出力」**で一括ダウンロード可能です。

### ⑤ ODPT リアルタイム運行情報ステータス盤＆豪雨運休シミュレータ
ヘッダー右側の**「🚆 運行情報」**ボタンをクリック。
- **都営地下鉄4路線（浅草線・三田線・新宿線・大江戸線）**、都営バス、JR線のリアルタイム運行状況・遅延理由・振替輸送案内を一覧表示。
- **豪雨運休シミュレータ（模擬運休注入）**: 「☀️ 全線平常運行」「⚠️ 17:10 局地豪雨」「🚨 17:15 豪雨全線見合わせ」「🌊 首都激甚豪雨」をワンクリックで注入可能。晴天時の審査でも豪雨被災時の運転見合わせ発令を即座にシミュレートできます。
- **ODPT 本番APIキー連携**: 自身の ODPT トークンを入力することで本番APIへのライブフェッチにも対応（未設定でもキャッシュデータで完全動作）。

### ⑥ 駅出入口（GTFS-Pathways）＆ 一時滞在施設 3D避難ガイド
ヘッダーの**「🚪 出口・避難所」**ボタンで表示切替。
- **GTFS-Pathways 駅出入口（12箇所）**: 大門駅・浜松町駅・三田駅・田町駅・汐留駅の主要出入口を3D空間上にピン留め。デッキ直結の安全出口（B3/B4等＝緑色発光）と、すり鉢状アンダーパス冠水に直面する危険出口（A1/A3等＝赤色点滅）を雨量スライダーに応じて動的ハイライト。
- **都立・港区帰宅困難者一時滞在施設（6施設）**: 産業貿易センター浜松町館（2,500名収容）、ポートシティ竹芝（1,800名収容）、世界貿易センター南館、msb Tamachi等を可視化。出入口から地上浸水をくぐらず到達できる高架デッキ避難ルートを案内。

## 6. ローカル開発・セットアップ手順

本プロジェクトは軽量な Vite 構成となっており、数コマンドで開発環境を再現できます。

### 必要環境
- Node.js: v20 以上
- npm: v10 以上

### 手順
```bash
# 1. リポジトリのクローン
git clone https://github.com/junichikatsu/open-data-challenge2026.git
cd open-data-challenge2026

# 2. develop ブランチの確認
git checkout develop

# 3. 依存ライブラリのインストール
npm install

# 4. ローカル開発サーバーの起動
npm run dev
# -> http://localhost:5173/ がブラウザで立ち上がります

# 5. プロダクションビルドの確認
npm run build
```
