# 案3+ データ一覧と取得手順

確認日: 2026-10-17（各データの公開と中身を実際に取得して確認）

## 置き場所

| フォルダ | 中身 |
| --- | --- |
| `data/raw/` | 取得したままの原本（PDF、XLSX、GTFS zip など） |
| `data/processed/` | 機械可読化・加工したもの |

ODPT と PLATEAU の大きなデータは共有ドライブに置かず、取得手順だけを残す。チャレンジ用の提供データは応募作品以外に使えず、第三者提供も禁止（応募規約25・27）。

## `underpass_tokyo_159.csv` の列

| 列 | 内容 |
| --- | --- |
| no | リストの番号（1〜159） |
| municipality | 区市町村 |
| road_type | 国道・都道・区道・市道・臨港道路・区有通路 |
| route_and_name | 路線名と地先名・通称 |
| rail_crossing_guess | 鉄道交差の推定（1/0）。名称のキーワードによる推定で、人手で確定する必要がある |
| lat, lon | 空欄。ジオコーディングで埋める |
| location_confidence | 空欄。高・中・低を付ける |
| source | 出典と時点 |

内訳: 都道76、区道31、国道24、市道22、臨港道路5、区有通路1。港区5、千代田区2、中央区6。
