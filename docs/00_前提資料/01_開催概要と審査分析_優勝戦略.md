* **応募資格**：

## 2. 2026年大会の重点トレンドと注目データセット

本コンテストは国土交通省の国家的DXプロジェクト（**Project LINKS**、**COMmmmONS**）と強力に連携しており、2026年大会ならではの注力分野が設定されています。

### 2.1 重点テーマ
* **地方都市圏・過疎地の「交通空白」解消**（担い手不足、路線廃止、通院・通学難民へのアプローチ）
* **駅構内・歩行空間の「バリアフリー」推進**（高齢者、車椅子、ベビーカー利用者、訪日外国人対応）
* **官民横断のデータ連携**（公共交通 × 都市空間 3D × 気象・安全・統計データ）

### 2.2 活用可能な主要データ群
1. **公共交通オープンデータセンター / GTFSデータリポジトリ（必須基盤）**
   * **鉄道・バス**：時刻表（GTFS）、列車・バスロケーション（GTFS-RT / VehiclePosition, TripUpdate）
   * **デマンド交通（GTFS-Flex）**：国内初の規格化が進むオンデマンド配車・乗合タクシーデータ
   * **フェリー・航空**：航路情報、フライト時刻表・発着情報
   * **シェアサイクル（GBFS）**：ドコモ・バイクシェア、OpenStreet（HELLO CYCLING）のリアルタイムステーション情報
2. **駅構内・歩行空間データ（ほこナビプロジェクト）（★注力データ）**
   * 都営地下鉄（大江戸線12駅等）の歩行空間ネットワークデータ、構内地図データ、GTFS-Pathwaysデータ
   * 通路幅、段差・勾配、エレベーター・エスカレーターの接続関係情報
3. **都市・行政連携オープンデータ（強く推奨）**
   * **Project PLATEAU**：全国主要都市の3D都市モデル
   * **Project LINKS / 国土交通データプラットフォーム**：国土交通分野のオープンデータ
   * **警察庁**：交通事故統計情報、交通規制データ
   * **気象庁**：気象データ高度利用ポータル
   * **総務省 e-Stat**：国勢調査等の政府統計データ
   * **東京都**：東京都オープンデータカタログ、道路工事情報

## 4. 優勝（最優秀賞・上位入賞）に必要な5大勝因要素

過去の受賞作（2025年最優秀「Safe Pedal」、2024年最優秀「急がば漕げマップ」、2019年最優秀「Mini Tokyo 3D」、2021年「密予報」「PIEN」等）の共通点から抽出した成功原則です。

```
                ┌──────────────────────────────────────────────┐
                │        最優秀賞を勝ち獲るコアアーキテクチャ       │
                └──────────────────────┬───────────────────────┘
                                       │
         ┌─────────────────────────────┼─────────────────────────────┐
         ▼                             ▼                             ▼
┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
│ ① 異種データの融合 │          │ ② 国策データの先駆 │          │ ③ 課題の切実さと   │
│ (公共交通 × 外部)  │          │ (Flex / Pathways)│          │    ストーリー性   │
└──────────────────┘          └──────────────────┘          └──────────────────┘
         │                             │                             │
         └─────────────────────────────┼─────────────────────────────┘
                                       │
                        ┌──────────────┴──────────────┐
                        ▼                             ▼
              ┌──────────────────┐          ┌──────────────────┐
              │ ④ 圧倒的UI/UX    │          │ ⑤ 審査プレゼンの   │
              │ (WOW体験・可視化) │          │    再現性と完成度 │
              └──────────────────┘          └──────────────────┘
```

### ① 「公共交通データ × 異種オープンデータ」の掛け算（最重要）
* **現状**：単に時刻表を表示したり、バスの現在地をマップにプロットするだけの作品は飽和しており、審査員に刺さりません。
* **勝ち筋**：公共交通データに**「警察庁（規制・事故）」「ほこナビ（歩行空間）」「PLATEAU（3D都市）」「気象庁」「人流・統計（e-Stat）」**など別次元のオープンデータを掛け合わせ、**「これまで見えなかった移動の最適解」**を可視化すること。
  * *実績*：2025年最優秀「Safe Pedal」は、シェアサイクルGBFS × 警察庁交通規制データを融合し、安全重視ルートを算出。

### ② 大会が今最も推進したい「先駆的データ形式」の採用
* 主催者（ODPT・国交省・MobilityData）は、新しく公開したデータが実際に使われることを強く期待しています。
* **今大会のボーナス枠**：
  * **GTFS-Flex**（デマンド交通・オンデマンド配車）
  * **GTFS-Pathways / ほこナビ**（駅構内段差・エレベーター・歩行空間ネットワーク）
* これらを活用した作品は、「オープンデータ整備の社会的重要性を証明した作品」として審査会での評価が跳ね上がります。

### ③ 解像度の高い課題設定とストーリー性（政策×現場）
* 「誰の」「どんな痛み（Pain）」を解消するのかが曖昧なツールは高得点になりません。
  * **地方都市**：免許返納高齢者の通院・コミュニティバスとデマンド交通の乗継ぎ分断
  * **大都市ターミナル**：車椅子・ベビーカー利用者がエレベーター点検時や混雑時に直面する「駅構内の迷宮」
  * **観光地**：オーバーツーリズムによる主要路線のパンクと、裏ルート・シェアサイクル等による分散
* 自治体や交通事業者が「これなら自分たちの街にすぐ導入したい」と思える実用性と説得力が必要です。

### ④ 触れた瞬間に引き込まれる「WOW体験」とUI/UX
* 生成AIの普及により、誰もがコードを書ける時代になったからこそ、**UIの洗練度・デザインの美しさ・インタラクションの心地よさ**が決定的な差別化になります。
* 審査員にはMapboxアンバサダーの草薙氏もおり、以下のような要素が強力な武器になります：
  * Mapbox / Deck.gl / Three.js などを駆使した滑らかな地図・3D・リアルタイム可視化
  * ユーザーが直感的にパラメーターを変えられる操作性（スライダー、フィルタリング等）
  * モバイル／デスクトップのレスポンシブ対応と高い表示パフォーマンス

### ⑤ 審査会（ヒアリング・プレゼン）に耐えうる実動と完成度
* 応募規約上、**一般公開されて誰でも無償で触れる状態**である必要があります。
* エラーで動かない箇所がない堅牢な実装と、1分で価値が伝わるデモ動画・紹介スライドの設計が一次審査突破の生命線となります。
