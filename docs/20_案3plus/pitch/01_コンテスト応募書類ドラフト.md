## 2. 作品の一言要約（100文字程度）

豪雨で電車が止まった際、冠水したアンダーパスを避けて安全に避難できるよう、ODPT運行情報・駅出入口・都営バスとPLATEAU 3D都市空間、国交省冠水注意箇所を融合したフェーズフリー避難ナビです。（98文字）

## 3. 解決する社会課題（なぜ今、これが必要なのか）

### 3.1 2026年豪雨被害が突きつけた「都市の盲点」
2026年の台風・線状降水帯による局地豪雨では、千葉県で2名、いわき市で1名がアンダーパス内で車ごと水没して亡くなる痛ましい事故が発生しました。名古屋市でも地下鉄が運転見合わせになる直前にアンダーパスで車が立ち往生するなど、大都市圏でも生命の危機に直結する事態が相次ぎました。

### 3.2 本作品が解消する「3つの分断と落とし穴」
1. **情報の分断（交通情報と道路防災情報の乖離）**:
   - 鉄道の運行情報（GTFS-RT）と道路の冠水リスク（国交省注意箇所）は別々の機関から発表されており、帰宅困難者が同一の地図上で同時に把握する手段がありませんでした。
2. **駅出口の落とし穴（GTFS-Pathwaysの死角）**:
   - 電車が運転見合わせになった際、利用者が駅の出入口選択を誤ると、地上に出た直後にすり鉢状の冠水アンダーパスに直面してしまいます（例: 大門駅A1出口を出ると目前のJR架道橋冠水に巻き込まれる）。
3. **行政データの非構造化と自治体管理者の負担**:
   - 国土交通省が公表するアンダーパス冠水注意箇所リスト（都内159箇所・全国約3,800箇所）はPDF形式に留まり、緯度経度やバス路線（GTFS shapes）との空間結合がなされていませんでした。さらに、**2026年10月6日改定の国交省新ガイドライン**で求められる「4区分判定（特定アンダーパス等の判定）」を、全国約3,700箇所の自治体道路管理者が限られた人員で判断しなければならないという切実な行政課題があります。

## 4. 活用したオープンデータ一覧（多層データフュージョン）

本作品は、ODPTが提供する最新の公共交通オープンデータと、国土交通省の国家的DX基盤（PLATEAU・道路防災・DEM）を高度に空間結合しています。

| No | データセット名 | 提供元 | 本システムでの役割・加工内容 |
|:---:|:---|:---|:---|
| **1** | **都営地下鉄 GTFS-Pathways（駅出入口）** | 公共交通オープンデータ協議会 (ODPT) | 大門駅・三田駅等の主要出入口の位置とアンダーパス空間結合。雨量・水位に応じた「冠水危険出口（A1/A3等）」と「デッキ直結安全出口（B3/B4等）」の動的判定。 |
| **2** | **都営地下鉄 運行情報 (GTFS-RT)** | 公共交通オープンデータ協議会 (ODPT) | 豪雨時の都営4路線＋JRの運転見合わせ・遅延情報の受信とタイムライン連動。晴天時でも審査可能な「模擬運休注入シミュレータ」の実装。 |
| **3** | **都営バス 路線形状 (GTFS shapes)** | 公共交通オープンデータ協議会 (ODPT) | アンダーパス冠水危険箇所を通過する路線（浜95系統等）の警告と、冠水を避けて運行継続する安全代替幹線（都06系統等）の自動抽出・乗換誘導。 |
| **4** | **道路防災情報「アンダーパス冠水注意箇所」** | 国土交通省 関東地方整備局 道路部 | PDF公表の都内159箇所を全件ジオコーディングし、鉄道交差フラグ・標高・バス路線交差数を結合した構造化GeoJSONとして完全機械可読化。 |
| **5** | **Project PLATEAU 3D都市モデル** | 国土交通省 | 港区LOD1/LOD2 建築物モデル（世界貿易センタービル、ポートシティ竹芝等）をMapLibre 3D空間に発光レンダリング。ペデストリアンデッキ避難路を視覚化。 |
| **6** | **AWS Open Data Terrarium DEM** | Mapzen / 国土地理院 | 標高メッシュによる3D地形表現。すり鉢状窪地への降雨集水・冠水水位上昇の動的3Dシミュレーション。 |
| **7** | **都立・区立 帰宅困難者一時滞在施設** | 東京都・港区 | 産業貿易センター浜松町館（2,500名収容）、ポートシティ竹芝等の収容規模・施設情報と高台デッキ避難誘導。 |

## 5. 主要機能と利用シーン（フェーズフリーな設計）

平常時の「事前学習・市民点検」から、豪雨時の「避難・迂回ナビ」、平常時・有事の「行政設備判定DX」までをシームレスにつなぐフェーズフリーな3つのモードを搭載しています。

```
          [ アメミチ 3D のフェーズフリー・エコシステム ]
 ┌─────────────────────────────────────────────────────────────┐
 │  ☀️ 平常時（市民・通勤者）                                  │
 │   ● アメミチづくり: 地図上に線を引いて冠水回避ルートを自作採点  │
 │   ● 見てきた報告: 現地設備（赤色灯・道路情報板・水位計）を3値点検│
 └──────────────────────────────┬──────────────────────────────┘
                                │ データ蓄積・事前学習
 ┌──────────────────────────────▼──────────────────────────────┐
 │  🚨 豪雨時（帰宅困難者・避難者）                             │
 │   ● 17:15 シナリオ再生: 運休発生時に安全な駅出口・バスを即時ナビ│
 │   ● 出口アメミチ: 冠水出口を避け、ペデストリアンデッキ直結出口へ│
 └──────────────────────────────┬──────────────────────────────┘
                                │ 防災安全性の担保
 ┌──────────────────────────────▼──────────────────────────────┐
 │  🏛️ 行政・道路管理者（自治体DX）                            │
 │   ● 4区分判定ダッシュボード: 都内159箇所の国交省新基準自動判定  │
 │   ● ワンクリックCSV出力: 防災計画・予算要望へのエビデンス活用   │
 └─────────────────────────────────────────────────────────────┘
```

### ① 平時モード「アメミチづくり（安全避難ルート描画＆幾何採点）」
- ユーザーが地図上をクリックして自宅や目的地までのルートを描線。
- アルゴリズムがアンダーパス危険バッファ（250m/120m/50m）、標高勾配、都営バス安全幹線との近接度をリアルタイムに幾何計算し、**100点満点で即座に採点＆S/A/B/Cランク診断モーダル**を表示。
- 雨量スライダー（0〜100mm/h）を動かすことで、「どこがすり鉢状の窪地で、何ミリ降ると沈むのか」を身体感覚として学べます。

### ② 平時モード「見てきた（現地設備3値点検＆市民協働）」
- 地図上のアンダーパスピンをクリックすると、「赤色回転灯」「道路情報板」「水位センサ・標示」の有無を3値（はい／いいえ／わからない）で報告。
- 複数人の報告一致により設備ステータスが更新され、管理者ダッシュボードへリアルタイム反映。
- **防災フェイルセーフ**: 雨量スライダーが50mm/h以上の豪雨シミュレーション中は、市民が危険箇所を見に行かないよう現地調査ボタンを自動でロック（無効化）します。

### ③ 豪雨時モード「17:15 シナリオ再生エンジン（避難・迂回ナビ）」
- 審査時に雨が降っていなくても、**「17:15 ゲリラ豪雨シナリオ」**をワンクリックでシネマティックに再生可能。
  - **16:50**: 降雨開始（20mm/h）
  - **17:10**: 65mm/hの猛烈な雨に急変。アンダーパスが警戒水位に到達。
  - **17:15**: 都営地下鉄（浅草線・大江戸線）全線運転見合わせが発令。すり鉢状窪地に面した「A1出口」が冠水危険により閉鎖表示。
  - **17:20**: 安全な「B3出口（デッキ直結）」および冠水を避ける**安全推奨ライン（アメミチライン）**が自動描画。冠水箇所を迂回して運行継続する**都営バス「都06系統」**への乗換誘導と、産業貿易センター浜松町館（2,500名収容）への高台避難指示を発動。

### ④ 管理者モード「国交省4区分判定ダッシュボード」
- 都内159箇所のアンダーパス注意箇所を一覧表示。
- エリア（港区・品川区・新宿区・渋谷区等）、鉄道交差有無、通過バス系統数で瞬時にフィルタリング。
- 国交省ガイドライン（2026-10-06改定）の判定ロジックに基づき、特定アンダーパス等の4区分を自動仮判定し、根拠とともにCSVダウンロードが可能です。

## 6. 技術的な工夫点と独創性

1. **MapLibre GL 3D Terrain と動的水位レンダリング**:
   - AWS Open Data Terrarium DEM タイルを採用し、GPU負荷を抑えつつ滑らかな3D地形を生成。標高値に応じた動的シェーディングにより、雨量スライダーに合わせて窪地へリアルタイムに水が満ちていく視覚的インパクトを実現しました。
2. **高速幾何計算による安全度スコアリングアルゴリズム**:
   - 描画されたポリライン座標列に対し、アンダーパス危険バッファとの交差判定および最近接距離をミリ秒単位で幾何計算。ゲーム感覚で防災リテラシーを高めるUI設計。
3. **タイムライン連動型シナリオ再生エンジン（模擬運休注入）**:
   - 豪雨時の刻々と変化する気象情報・鉄道運休・道路冠水・出口閉鎖・バス誘導・カメラワークを単一のステートマシンで統制。倍速再生（1x/2x/5x）にも完全対応。
4. **モバイル（スマートフォン）完全最適化とPWA対応**:
   - スマホ縦画面（幅360px〜480px）に最適化した多段2列グリッドヘッダーと、下部から滑らかにスライドアップするボトムシートUIを実装。Web App Manifestによりホーム画面追加によるスタンドアロン起動も完備。

## 8. 今後の発展性（社会実装に向けたロードマップ）

1. **全国3,800箇所への展開**:
   - 現在の都内159箇所から、全国各自治体のアンダーパス注意箇所データおよび全国GTFSオープンデータを取り込み、全国展開を推進します。

   - 市民報告に加え、自治体・国交省が設置を進める小型超音波水位計や道路カメラ画像解析AIとのデータ連携を検証します。
3. **GTFS-Flex（デマンド交通）との接続**:
   - 幹線道路冠水時におけるデマンド乗合タクシーの柔軟な迂回配車リクエストとの連動を視野に入れています。
