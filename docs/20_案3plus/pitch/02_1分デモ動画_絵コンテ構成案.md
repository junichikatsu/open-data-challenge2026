# 審査応募用 1分デモ動画 絵コンテ・タイムライン構成案

---

## 1. 動画の基本仕様

* **目標尺**: 60秒（1分00秒）※コンテスト規定・審査員の集中力維持に最適化
* **解像度**: 1920 × 1080 (16:9 Full HD) または 4K
* **アスペクト比**: 16:9（YouTube等での審査員視聴）
* **音声構成**:
  * BGM: 洗練されたサイバー感・緊迫感から安心感へ移るアンビエント/エレクトロニック系
  * ナレーション: 明瞭で落ち着いた日本語音声（AI音声合成 / VOICEPEAK等推奨）
  * 効果音（SE）: 雨音、アラート音、UIクリック音、歓声/ピン音

## 3. 画面キャプチャ撮影のポイント（失敗しないためのチェックリスト）

1. **ブラウザ設定**:
   - Chrome等のフルスクリーンモード（F11または緑ボタン長押し）を使用。
   - ブックマークバーやアドレスバーを非表示にする。
   - ローカル開発環境（`http://localhost:5173/`）または本番URLでスムーズに録画。
2. **マウスカーソルの動き**:
   - カーソルを激しく動かさず、視聴者の視線を誘導するように滑らかに移動させる。
3. **倍速再生の活用**:
   - シナリオ再生時は右上の「2x」または「5x」ボタンを使ってテンポよく見せる。
4. **スマホ実機の挿入（ラスト5秒）**:
   - iPhone / Androidの画面収録で、ホーム画面アイコンからアプリが起動する様子を合成すると完成度が際立ちます。
